常见问题

如何把音乐放进 App？

两种方式：在「资料库」右上角 + 选择「导入音乐 / 歌词」从「文件」App 选取； 或打开「传输」页开关，在同一 Wi-Fi 下用电脑浏览器访问页面显示的地址，把文件拖进网页即可。 同名 .lrc / .srt 歌词会自动关联。

支持哪些格式？

FLAC、ALAC、WAV、AIFF、MP3、AAC / M4A、Ogg Vorbis、CAF、DSF 等， 按文件头识别真实格式。APE、WavPack、WMA、TTA 暂不支持，导入时会明确提示。

为什么音量滑杆和物理音量键是同步的？

App 使用系统音量控制，与物理按键、控制中心、锁屏音量条是同一套值。 睡前定时只做渐隐，不会改动系统音量。

私密文件夹安全吗？

使用系统 Face ID / 设备密码与 AES-256-GCM 加密，密钥仅保存在本机钥匙串， 不上传、不同步 iCloud。移入即加密，移出即解密。重录 Face ID 或抹掉设备后旧密钥会失效， 重要文件请定期移出备份。

播放到最后一首如何循环？

播放器右下角循环按钮依次切换「不循环 → 列表循环 → 单曲循环」， 切换时会显示当前模式。列表循环播完最后一首会回到第一首。

需要联网或账号吗？

不需要。App 不连接任何服务器，没有账号体系，也不收集或上传任何数据。 Wi-Fi 传输仅在用户主动开启时于本机局域网内监听。
